# Test Summary

## Overview

A lightweight exploratory QA review was performed against the publicly accessible ShopUp website.

The review focused on identifying user-facing issues across content, UI consistency, accessibility, and related website sections.

## Findings

| ID | Area | Severity | Status |
|---|---|---|---|
| BUG-001 | Testimonial / Content | Medium | Open |
| BUG-002 | Domain / Consistency | Medium* | Open |
| BUG-003 | Blog / CMS | Medium | Open |
| BUG-004 | Job Posting / Content | Low–Medium | Open |
| BUG-005 | Accessibility | Medium | Open |

## Key Observations

The exploratory review identified issues involving:

- Content-to-image consistency
- Homepage and related-page content synchronization
- Duplicate job-posting information
- Image alternative text
- Cross-domain content consistency

## Recommendation

Each finding should be reviewed against the intended product/content requirements before assigning final severity and priority.
