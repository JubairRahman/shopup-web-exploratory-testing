# Testing Scope

## Objective

Perform exploratory testing of the publicly accessible ShopUp website and identify reproducible user-facing issues.

## In Scope

- Homepage
- About / company information
- Careers
- Job postings
- Blog
- Navigation
- Links
- UI consistency
- Content consistency
- Accessibility
- Responsive behavior
- Basic browser compatibility
- HTML / DOM inspection

## Out of Scope

- Authentication bypass
- Unauthorized access
- Security exploitation
- Load / stress testing against production
- Destructive testing
- Database testing
- Internal APIs
- Private/admin functionality
- Personal or confidential data

## Testing Approach

Exploratory testing was performed by navigating the website as a normal user and investigating inconsistencies or unexpected behavior.

Findings are documented only after reproduction and verification.
